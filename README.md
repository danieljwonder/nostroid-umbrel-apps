# Nostroid App Store for Umbrel

Nostr tools for Umbrel, as an [Umbrel community app store](https://github.com/getumbrel/umbrel-community-app-store).

## Add it to Umbrel

App Store → `…` (top right) → **Community App Stores** → paste
`https://github.com/danieljwonder/nostroid-umbrel-apps` → **Add**.

## Apps

| App | What it is |
|---|---|
| [nak bunker](nostroid-nak-bunker) | Self-hosted Nostr remote signer (NIP-46): the bunker from [nak](https://github.com/fiatjaf/nak), unmodified, with web setup and unlock. Source: [nak-bunker-umbrel](https://github.com/danieljwonder/nak-bunker-umbrel). |

Community apps are not reviewed by Umbrel. Read the source before installing anything that holds keys.
